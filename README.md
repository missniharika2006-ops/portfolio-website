# Niharika Gautam — Personal Portfolio

A responsive, single-page portfolio for a second-year B.Tech CSAIML student. Built with semantic HTML, custom CSS and vanilla JavaScript.

## Run locally

Open `index.html` in a modern browser. No build step or package installation is required. Google Fonts and Font Awesome are loaded from CDNs; the site remains usable without them.

## Project layout

```text
personal-portfolio/
├── index.html
├── css/
│   ├── style.css
│   └── responsive.css
├── js/
│   ├── script.js
│   ├── animations.js
│   └── validation.js
├── images/
│   ├── profile/
│   ├── projects/
│   └── certificates/
├── resume/
│   └── Niharika_Gautam_Resume.html
└── README.md
```

The requested sections are organised on one navigable page so visitors can move smoothly between them without duplicate page templates. The project overview on the page visualises the user journey, technical flow, folder structure, technologies and interactive features.

## Included

- Responsive navigation with a mobile menu and smooth section links
- Light/dark theme toggle with saved preference
- Scroll reveal effects, loading screen and animated skill indicators
- Project-category filters and back-to-top control
- Contact form validation and a `mailto:` handoff (no server required)
- Downloadable, print-ready resume HTML; print it and select “Save as PDF” for a PDF copy
- Reduced-motion support and keyboard-visible focus styles
